## 1. はじめに

NoteFit AI（以下「本アプリ」）は、食事・トレーニング・体重の記録を支援し、AI によるアドバイスを提供するフィットネスアプリです。本プライバシーポリシーは、本アプリが収集・利用・保護する情報について説明します。

---

## 2. 収集する情報

### 2.1 ユーザーが直接入力する情報

| 情報の種類 | 収集タイミング | 用途 |
| --- | --- | --- |
| メールアドレス・パスワード | アカウント登録時 | Firebase Authentication によるログイン認証 |
| ユーザーネーム | プロフィール設定時 | アプリ内での表示名 |
| 身長・生年月日 | プロフィール設定時 | カロリー自動計算。AI には満年齢のみ送信 |
| 体重・体脂肪率 | 日々の記録時 | 進捗トラッキング、グラフ表示、AI アドバイス生成 |
| 食事内容（テキスト） | 食事記録時 | AI による PFC（栄養素）推定、食事履歴の管理 |
| トレーニング記録 | トレーニング記録時 | 進捗トラッキング、統計表示、AI アドバイス生成 |
| 目標設定（減量/維持/増量、目標体重、目標カロリー） | 目標設定時 | AI アドバイスのパーソナライズ |
| AI コーチへのチャット本文 | AI 相談時 | 回答の生成 |
| AI コーチのスタイル設定 | 設定時 | 口調・指導スタイルの反映 |

### 2.2 自動的に収集する情報

| 情報の種類 | 用途 |
| --- | --- |
| 広告識別子（広告 ID） | Google AdMob による広告配信の最適化 |
| デバイス情報（OS バージョン等） | 広告配信およびアプリの互換性確保 |

本アプリは、現時点で Firebase Analytics による利用状況の計測は行っていません。

---

## 3. 情報の利用目的

収集した情報は、以下の目的にのみ使用します。

1. **アカウント管理**: ユーザー認証、ログイン状態の維持
2. **アプリの主要機能の提供**: 食事・トレーニング・体重の記録、統計表示
3. **AI 機能の提供**: 食事の栄養素推定、日次アドバイス生成、AI コーチとのチャット
4. **広告配信**: Google AdMob を通じた広告の表示（無料プランのユーザー）
5. **サブスクリプション管理**: RevenueCat を通じた課金状態の管理

---

## 4. 第三者への情報提供

本アプリは、以下のサービスに情報を送信します。

| サービス | 送信する情報 | 目的 |
| --- | --- | --- |
| **Firebase**（Google） | メールアドレス、プロフィール、食事・トレーニング・体重などのアプリデータ | 認証、データベース、Cloud Functions |
| **OpenAI** | 下記「OpenAI に送信する情報」 | 栄養素推定・日次アドバイス・チャット回答の生成 |
| **Google AdMob** | 広告識別子、デバイス情報 | 広告配信 |
| **RevenueCat** | ユーザー ID、購入情報 | サブスクリプション管理 |

### OpenAI に送信する情報

機能に応じて、次の情報を API 経由で送信します。メールアドレスやユーザー ID は送信しません。生年月日そのものは送信せず、満年齢のみを送ります。

- **食事の栄養素推定**: 入力した食事テキスト、任意で身長・満年齢
- **日次アドバイス**: 目標（減量/維持/増量、目標体重、目標カロリー）、当日および直近の体重・体脂肪率、当日の食事記録（カロリー・PFC・品目名）、直近のトレーニング記録、身長・満年齢、トレーニング段階、ジム通いの有無、AI コーチのスタイル設定
- **AI コーチチャット**: チャット本文、上記と同様の記録・目標・身体情報（同期できる場合）、AI コーチのスタイル設定

API 経由で送信されたデータは、OpenAI の言語モデルの学習には使用されません。

本アプリは、サービスの提供のため、日本国外にサーバーを置く事業者に情報を提供する場合があります。これらの事業者は、それぞれのプライバシーポリシーに基づきデータを管理します。

---

## 5. データの保管と保護

- ユーザーデータは **Google Cloud（Firebase）** のサーバーに暗号化して保管されます
- サーバーリージョン: `asia-northeast1`（東京）
- Firestore セキュリティルールにより、各ユーザーは自分自身のデータにのみアクセスできます
- パスワードは Firebase Authentication によりハッシュ化されて保管されます

---

## 6. データの保持期間

- アカウントが有効な間、データは保持されます
- アカウント削除時、Firebase Authentication のユーザー情報は即座に削除されます
- Firestore 上のユーザーデータはアカウント削除後 30 日以内に削除されます

---

## 7. ユーザーの権利

ユーザーは以下の権利を有します。

- **データの閲覧**: アプリ内でご自身のすべてのデータを閲覧できます
- **データの修正**: プロフィール情報、記録データはいつでも修正できます
- **アカウント削除**: 設定画面からアカウントを削除できます
- **Google Play 向けアカウント削除申請フォーム（Web）**: アプリをアンインストール済みの場合や、ブラウザから手続きしたい場合は、[NoteFit AI アカウント削除リクエスト（Google フォーム）](https://forms.gle/uxPFopd5VdbTB2mX8)から申請できます。
- **データ削除の要求**: [notefit-ai@gmail.com](mailto:notefit-ai@gmail.com) にご連絡いただければ対応します
- **広告トラッキングの無効化（オプトアウト）**: ご利用の端末の設定から、パーソナライズされた広告の表示（トラッキング）を制限することができます。
- **プライバシーポリシーの再確認**: 設定画面から本ポリシーをいつでも閲覧できます。
